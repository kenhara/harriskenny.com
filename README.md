# harriskenny.com

Personal site for Harris Kenny.

Theme-independent data in `js/data.js`. Desktop chrome is a skin. Drag **Time Machine** along the top bar to jump:

DOS → Windows 3.1 → Windows 95 → Mac OS 8 → Mac OS X → Debian → Pop!_OS → MacOS → Omarchy

Omarchy is a folder (Kids plus the six plugins). Sparklekeys lives in that folder, not on the desktop.

Icons restyle per era. Wallpapers: real assets throughout — see `wallpapers/LICENSES.md`. DOS is CSS scanlines, Windows 95 is solid teal, Windows 3.1 and Mac OS 8 use the supplied pattern images, later eras use photos.

Open `index.html`. Mobile skins later. GitHub Pages / DNS / deploy are out of scope.
