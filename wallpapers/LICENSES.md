# Wallpaper sources

Real, freely-licensed default wallpapers used for the open-source eras. Nothing here is AI-generated or invented — each is the actual shipped asset, downsized for web.

## Debian (`debian.jpg`)
- Source: `salsa.debian.org/debian-desktop-team/desktop-base`, `emerald-theme/wallpaper/contents/images/5120x2880.svg`
- This is Debian's own default desktop-base theme ("Emerald"), artist Juliette Taka Belin.
- License: GPL-2+ (per the package's `debian/copyright`).

## Pop!_OS (`popos.jpg`)
- Source: `github.com/pop-os/wallpapers`, `original/kate-hazen-pop-m3lvin.png`
- Official System76 wallpaper by Kate Hazen.
- License: CC BY-SA 4.0 (per the repo's README).

## Omarchy (`omarchy.jpg`)
- Source: `github.com/basecamp/omarchy`, `themes/tokyo-night/backgrounds/0-winding-road.webp`
- The real default "Tokyo Night" theme background Omarchy ships with out of the box.
- License: MIT (repo-wide license, David Heinemeier Hansson).

## Mac OS X "Aqua Blue" (`osx.jpg`)
- Source: 512pixels.net's macOS wallpaper archive, `10-0_10-1-6k.jpg` (Cheetah & Puma) — a hand-upscaled 6K restoration of Apple's original Mac OS X 10.0/10.1 default wallpaper.
- Copyright: the original artwork is Apple's; this is a fan restoration hosted publicly for download, not under a stated open license. Used here with Harris's explicit go-ahead for his own personal, non-commercial tribute site.

## Current macOS (`macos.jpg`)
- Source: 512pixels.net's macOS wallpaper archive, `15-Sequoia-Light-6K.jpg` — Apple's official macOS Sequoia default wallpaper.
- Copyright: Apple's. Same basis as above — personal, non-commercial use with the site owner's explicit direction.
